# How React Works

React creates a Virtual DOM, which is a lightweight copy of the Real DOM.

When data changes:

1. React creates a new Virtual DOM.
2. Compares it with the previous Virtual DOM.
3. Finds the differences.
4. Updates only the changed elements in the Real DOM.

This process is called Reconciliation.

## Benefits

- Faster UI Updates
- Better Performance
- Improved User Experience

## Learning Outcome

Understand how React efficiently updates the user interface.
