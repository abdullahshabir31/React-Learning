# Create React App vs Vite

| Create React App     | Vite                         |
| -------------------- | ---------------------------- |
| Slower startup       | Very fast startup            |
| Larger bundle        | Optimized bundle             |
| Older tooling        | Modern tooling               |
| Slower Hot Reload    | Fast HMR                     |
| Less preferred today | Recommended for new projects |

## Why We Use Vite

- Faster Development Server
- Better Performance
- Instant Hot Module Replacement (HMR)
- Simple Configuration
- Officially Recommended for Modern React Projects

## Learning Outcome

Understand why Vite has become the preferred tool for creating modern React applications.
