# State

This folder contains practical examples of React State using the `useState` Hook.

State allows React components to store and manage data that can change over time. When state changes, React re-renders the component and updates the user interface.

## 📚 Topics Covered

- Basic useState
- Updating State
- Multiple State Variables
- State with Input
- State with Objects
