# JSX

This folder contains beginner-friendly examples of JSX (JavaScript XML), the syntax extension used in React to build user interfaces.

## 📚 Topics Covered

- JSX Syntax
- JSX Expressions
- JSX Attributes
- JSX Fragments
- JSX Comments

## 📂 Folder Structure

```text
02-JSX/
├── 01-jsx-syntax.jsx
├── 02-jsx-expressions.jsx
├── 03-jsx-attributes.jsx
├── 04-jsx-fragments.jsx
├── 05-jsx-comments.jsx
└── README.md
```

## 🎯 Learning Outcome

After completing this folder, you will understand how JSX works, how to use expressions and attributes, how fragments help avoid unnecessary wrapper elements, and how to write comments inside JSX.
