# React Introduction

This folder contains beginner-friendly examples that introduce the fundamentals of React. These examples provide a basic understanding of React, why it is used, how it works, and why modern React projects commonly use Vite.

## 📚 Topics Covered

- What is React?
- Why React?
- React vs JavaScript
- How React Works
- Create React App vs Vite

## 📂 Folder Structure

```text
01-Introduction/
├── 01-what-is-react.jsx
├── 02-why-react.jsx
├── 03-react-vs-javascript.jsx
├── 04-how-react-works.jsx
├── 05-create-react-app-vs-vite.jsx
└── README.md
```

## 💻 Learning Approach

Each topic is implemented as a separate React component to help understand both the concept and its practical implementation. Every example can be rendered through `App.jsx` for hands-on learning.

## 🎯 Learning Outcome

After completing this folder, you will:

- Understand what React is.
- Know why React is widely used.
- Learn the difference between React and JavaScript.
- Understand how React updates the UI.
- Know why Vite is the preferred tool for modern React development.
