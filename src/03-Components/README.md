# Components

This folder contains beginner-friendly examples of React Components. Components are the building blocks of every React application and help create reusable and maintainable user interfaces.

## 📚 Topics Covered

- Functional Components
- Nested Components
- Component Import & Export
- Component Composition
- Reusable Components

## 📂 Folder Structure

```text
03-Components/
├── 01-functional-component.jsx
├── 02-nested-components.jsx
├── 03-component-import-export.jsx
├── 04-component-composition.jsx
├── 05-reusable-components.jsx
└── README.md
```

## 🎯 Learning Outcome

After completing this folder, you will understand how to create, organize, reuse, import, and compose React components.
